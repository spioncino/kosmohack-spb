# web

Назначение: мини-фронт для прогона пользовательского пути. Статика без сборки, plotly 2.35.2 в `vendor/`. Фронтендер заменит страницу целиком, контракт API не меняется.

## Пользовательский путь (О5)
задать окно и режим → задание в очереди и прогресс → таймлайн → предупреждения → правило и источники → открыть сырую запись → сравнение окон → выгрузка; панель источников для заморозки и принудительного обновления.

## Файлы
- `index.html` форма запроса (режим, отсечение, окно, период поиска, поле «Минимальная доля света в окне» 0–1 с пустым значением «не задано» и чекбокс «Старт на свету»), разделы результата, сырой записи и панель «Источники»; `style.css`; `app.js`:
  - `constraintsOf(form)`: `null`, если ни доля, ни чекбокс не заданы, иначе `{min_sunlit_fraction: число | null, start_in_daylight}`; `submit` добавляет `constraints` в тело только при непустом значении (D43).
  - `illuminationText(res)`: строка в блоке траектории из линии `illumination`: доля света за период поиска, самая длинная тень (метрики `sunlit_fraction`, `longest_shadow_minutes`) и освещённость старта запрошенного окна по интервалу линии, содержащему `requested_window.window.start`; без линии в ответе или при `availability != available` пишется это, а не значение.
  - В списке предупреждений линия `illumination` даёт только заголовок с метриками и пометкой «тень не предупреждение»; интервалы тени видны на таймлайне (`elevated`, жёлтый) и на карте; исключение окон по ограничению видно в колонке «Исключено» таблицы окон и в «Правилах».
  - `load`: `POST /jobs`, затем `waitJob` опрашивает `GET /jobs/{id}` каждые `POLL_MS` (1.5 с) и пишет `progress.step` с процентом в строку статуса; пока задание `queued`, показывается давность тика воркера из `GET /health`; при `done` грузится `GET /assessments/{assessment_id}` и вызывается `render`; при `failed` в строке статуса `error` задания.
  - `render`, `renderTimeline`, `renderMap`, `openEvidence` как раньше.
  - `loadSources`: таблица из `GET /sources` (продукты, период опроса, состояние, причина, последний успех и последняя запись как «N мин назад» через `ago`, число записей, последняя ошибка); кнопки «заморозить», «отключить», «активировать» вызывают `POST /sources/{name}/state` с причиной из поля над таблицей; «обновить» вызывает `POST /sources/{name}/refresh` и ждёт задание через `waitJob`; кнопка недоступна для неактивных источников, потому что воркер такое задание отклоняет.
- `sample_result.json` пример ответа `POST /assessments` по схемам `api/schemas.py` (шесть линий, включая `illumination` и `proton_access_geometry` по той же эфемериде OEM: доля света 0.954, тень 5 мин на 11 мая 2024 00:00–14:00); по `?sample=1` страница загружает его вместо заданий, панель источников в этом режиме сообщает, что API недоступен.
- `vendor/plotly.min.js` единственная внешняя библиотека, подключается только с этого пути.

## Инварианты
- Наблюдение, внешний прогноз и расчёт помечаются подписью `kind` у каждого интервала.
- Отсутствие данных показывается как `missing`/`unknown`, не как зелёная полоса; отсутствие тика воркера или успеха источника показывается словами «не запускался», «никогда», не пустой ячейкой.
- Времена в ответе принимаются с суффиксом `Z` и `+00:00`; сравнения времён идут через `Date`, не через строки.
- Длина полос таймлайна на оси дат задаётся в миллисекундах (соглашение plotly для `bar` с `base`).
- Опрос задания не имеет предела по времени: без воркера строка статуса так и остаётся «в очереди» с пометкой, что воркер не запускался.
- Тень показывается как условие работ, не как предупреждение: в штраф окон она не входит, окно исключается только по явно заданному ограничению из формы (D43).

## Как тестировать
- С API и воркером: `make api` и `make worker`, открыть `http://localhost:8000/`, нажать «Рассчитать» с предзаполненными значениями 10 мая 2024; в панели источников заморозить источник, убедиться, что воркер печатает `skipped: frozen`, и вернуть `active`. Отметить «Старт на свету» и повторить: окно 14:00 в таблице получает «ограничение освещённости: старт в тени» (тень 13:56–14:02 по эфемериде), в «Правилах» появляется строка ограничения.
- Без API: `uv run python -m http.server --directory web 8001`, открыть `http://localhost:8001/?sample=1`; переход к сырой записи и панель источников в этом режиме недоступны и показывают это в строке статуса.
