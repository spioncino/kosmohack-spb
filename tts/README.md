# tts: локальный синтез речи для сводки экипажу

Необязательный сервис. Основное приложение обращается к нему по адресу из `EVARISK_TTS_URL`, только когда сводка
запрошена с параметром озвучки. Без сервиса сводка работает как раньше: текст есть, аудио нет, на странице речь идёт
через синтез браузера.

## Движок
Silero TTS `v4_ru` (файл модели 40 МБ, `https://models.silero.ai/models/tts/ru/v4_ru.pt`), работает на CPU: 8 секунд
речи синтезируются примерно за 0.8 с на этой машине (4 потока). Дикторы: `kseniya` (по умолчанию), `xenia`, `baya`,
`aidar`, `eugene`. Лицензия моделей Silero CC BY-NC-SA 4.0: некоммерческое использование, для исследовательского
прототипа подходит; для коммерческого продукта движок заменяется, контракт сервиса остаётся.

## Почему текст должен быть словами
Модель не произносит цифры и латиницу и пропускает их молча: «Окно с 08:00 до 14:00 UTC» звучит как «Окно с до».
Времена выхода пропасть не должны, поэтому сервис отвечает 422 на любой текст с цифрой или латинской буквой, а
основное приложение передаёт `speech_text`, где времена, числа и обозначения записаны словами.

## Контракт
- `GET /`: страница проверки на слух: поле текста, выбор диктора, плеер, текст ошибки при отказе.
- `GET /health`: `status`, `engine`, `speakers`, `default_speaker`, `sample_rate`.
- `POST /synthesize` с JSON `{"text": "...", "language": "ru", "speaker": "xenia", "rate": "fast"}` (темп `slow`, `medium`, `fast`, `x-fast` через разметку SSML, по умолчанию из `TTS_RATE`): ответ 200 `audio/wav`
  (моно, 16 бит, 48 кГц). Длинный текст режется по предложениям, между кусками пауза 0.25 с.
- Ошибки в виде `{"error": {"code", "message"}}`: 400 для другого языка или неизвестного диктора, 422 для текста с
  цифрами или латиницей и для фрагмента, который модель не смогла произнести.

## Запуск на машине разработки
```sh
uv venv --python 3.12 tts/.venv
VIRTUAL_ENV=tts/.venv uv pip install --python tts/.venv/bin/python --index-url https://download.pytorch.org/whl/cpu torch
VIRTUAL_ENV=tts/.venv uv pip install --python tts/.venv/bin/python numpy fastapi "uvicorn[standard]"
scripts/dev_server.sh tts-start        # порт 8010, лог data/tts.log, модель в data/tts/v4_ru.pt
echo 'EVARISK_TTS_URL=http://localhost:8010' >> .env
```

Темп по умолчанию `fast`: на фразе сводки это 5.1 с против 6.3 с при `medium` и 4.1 с при `x-fast`. Формулировка тоже влияет на длину: «с восьми до четырнадцати часов» звучит 2.0 с, «с восьми ноль-ноль до четырнадцати ноль-ноль» 2.6 с.

Переменные: `TTS_RATE`, `TTS_MODEL_PATH` (по умолчанию `data/tts/v4_ru.pt`), `TTS_MODEL_URL`, `TTS_SPEAKER`, `TTS_SAMPLE_RATE`,
`TTS_THREADS` (по умолчанию 4).

## Проверка
```sh
curl -s localhost:8010/health
curl -s -X POST localhost:8010/synthesize -H 'content-type: application/json' \
  -d '{"text":"Выход в четыре ноль-ноль не рекомендую. Решение за руководителем работ."}' -o brief.wav
```
